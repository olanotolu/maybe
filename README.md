# Maybe

A tiny programming language where control flow is a decision.

`feels` asks a question. `match` routes between descriptions. `while` keeps
going until something stops feeling true. Every one of those is a single
forward pass through [jevbetter](https://github.com/olanotolu/jevbetter):
context in, one probability per option, no decoding.

```maybe
# demo/tavern.maybe
say "You push open the tavern door."

match "what do you do?":
  "order a drink at the bar" -> say "The bartender slides you a foaming ale."
  "pick a fight with the big guy in the corner" -> say "You wake up under a table."
  "sit quietly in the corner and watch" -> say "Nobody notices you. Good."

if feels "are you still thirsty?":
  say "You order another ale."
else:
  say "You settle your tab."

while feels "is anyone answering the door?":
  say "You knock again, louder."
```

Run it:

```bash
python -m maybe run demo/tavern.maybe
```

Sample output (decision traces shown with `~`):

```
You push open the tavern door. The room smells of ale and woodsmoke.
  ~ match "what do you do?" -> "order a drink at the bar" [order a drink at the bar 0.91, ...]
The bartender slides you a foaming ale.
  ~ feels "are you still thirsty?" -> yes (0.88)
You order another ale. The bartender nods approvingly.
...
```

## How it works

The interpreter keeps a *story*: everything `say` has printed so far. Each
decision feeds `story + question` as context into jevbetter, which scores the
options in one pass:

- `if feels "q":` — decide between `["yes", "no"]`, branch on the winner.
- `while feels "q":` — re-ask every iteration (max 8), so the story can change
  the answer.
- `match "q":` — the branch descriptions *are* the options; the winner's
  block runs.

The demo model (`demo/model.pt`) is a small jevbetter scorer trained on ~1000
menus generated by `demo/make_data.py`, covering the demo's decision points
and paraphrases. Regenerate and retrain with:

```bash
python demo/make_data.py
python -m jevbetter.train demo/data/train.jsonl --validation demo/data/validation.jsonl \
  --output demo/model.pt --width 64 --epochs 12 --device cpu
```

## The idea

An LLM writes; a decision model decides; a little program ties them together.
Branching on a calibrated probability beats branching on vibes: the program
can inspect, threshold, and log every choice it makes.
